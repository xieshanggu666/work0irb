# 自动化工厂流水线模拟游戏

一款**自动化工厂流水线**模拟游戏：采集矿石、冶炼金属、组装零件、研发科技、建造火箭并发射卫星。纯原生 **JavaScript + Canvas** 实现，零外部依赖，打开浏览器即可游玩。

## 快速开始

- **方式一（推荐）**：直接双击 `index.html`，浏览器中即可游玩。
- **方式二**：在项目目录下启动本地静态服务后访问，例如：

  ```bash
  python -m http.server 8000
  # 然后浏览器打开 http://localhost:8000
  ```

> 存档保存在浏览器 localStorage 中（3 个手动槽位 + 1 个自动槽位），也支持导出/导入 JSON 存档文件。

## 玩法目标

从零开始搭建一座自动化工厂：

1. **开采**：在铁矿/铜矿/煤矿脉上放置矿机，水域旁放水泵，油田上放抽油机。
2. **运输**：用传送带与机械臂把矿石送入熔炉，把产物送往组装机。
3. **生产**：熔炉冶炼矿石为金属板，组装机将零件加工成齿轮、电路板、发动机等，最终合成科学包。
4. **科研**：让实验室消耗科学包推进科技树，解锁更快的传送带、高级建筑与高级配方。
5. **通关**：研究「火箭科技」与「卫星发射」，生产火箭部件、火箭燃料与卫星，达成最终胜利目标。

## 资源链条

```
矿石 ──熔炉──> 金属板 ──组装机──> 零件（齿轮/铜线/电路板…）
零件 ──组装机──> 科学包（红/绿/蓝） ──实验室──> 科技解锁
原油+水 ──炼油厂──> 石油气/润滑油 ──化工厂──> 火箭燃料
```

共有 **26 种物品**（含 4 种流体）、**20 个配方**、**23 种建筑**、**14 个科技节点**。

## 核心系统

### 网格化地图
- 4 种程序化生成场景：**新手平原、沙漠油田、高山矿区、随机世界**。
- 可自定义尺寸（小/中/大）与随机种子；地形含草/沙/石/水，矿脉、油田随机分布。
- 支持多地图场景：每个存档独立保存整张地图的矿量与布局。

### 实时生产状态可视化
每个生产建筑有明确状态机：**生产中 / 缺料 / 堵塞 / 闲置 / 枯竭**。
- 按 `S` 在图上高亮所有建筑状态；
- 悬浮建筑显示配方进度、传送带载荷、管道液位、矿脉剩余储量。

### 科研科技树
- Canvas 绘制的科技树，支持拖拽、滚轮缩放、节点点击查看详情。
- 前置依赖系统：必须先完成前置科技才能开始后续研究。
- 未解锁的建筑在工具栏中置灰，点击可跳转科技树定位对应科技。

### 🚆 铁路货运
研究科技树中的「**铁路货运**」（物流学 II 之后）后解锁轨道、火车站与机务段：

- **铺轨建站**：轨道按住左键拖拽连续铺设，四向自动接轨、线路可任意交叉；**火车站**建在轨道旁（至少一侧接轨，本身即轨节点）；**机务段**用于编组发车。
- **运输计划**：在机务段点「编组列车」，选中列车后在右侧面板按顺序添加停靠站，每站设置**装货/卸货 × 物品 × 数量**；支持循环运输或单程（末站卸完自动驶离站台一格待命，让出站台）。
- **装货 / 行驶 / 卸货**：列车每节占 1 格，按 5 格/秒沿 BFS 最短路径行驶，到站后逐 tick（2 件/tick）与车站货位装卸；最短停站 0.5 秒，**15 秒最长停站超时强制离站**防止堵站。
- **闭塞分区（block）**：轨道按拓扑自动分区——道岔/交叉口/尽头（轨格度数 ≠ 2）各自独立成「道岔分区」，两段道岔之间的连续直线合并为一条「区间分区」（单线区段）。
- **区间预留（移动闭塞）**：列车每 tick 沿计划路径前瞻 5 格**一次性预留**（不再是逐格抢一格走一格），其他列车不能踏入已预留区间；预留是每 tick 重算的派生状态，列车只驶入自己已预留的格。
- **单线会车等待**：跨入一条区间分区前先申请该分区的**通行门（信号机）**——对向有来车（或区间内部有停靠/停运堵头）时门关闭，列车停在信号机外（道岔/上一区间末端）等待，**绝不顶进单线区段后再对顶**；同向前车不关门，可在其后跟驰排队（逐格预留保证不追尾）。无会车侧线、两端对顶无路可疏解时双车标红提示加侧线/改线。
- **交叉口公平通行**：道岔/交叉口是独立分区，抢不到的列车连交叉口格都不预留、停在自己一侧让交叉口保持清空；各方向来车按**轮转游标**申请门与交叉口，任一方向都不会被饿死。
- **拥堵绕行**：寻路从 BFS 升级为**加权 Dijkstra**——区间内有车/会车门关闭计高代价、被预占的道岔计中代价。主线拥堵而存在并行复线/会车侧线时列车自动选绕行路径；每 2 秒或门状态变化时重寻路。无路可达才进「断路」，有路但堵在门外进「会车等待」。
- **占用释放**：停运 / 解编 / 改计划（增删站点、跳过、切换循环、改装卸动作）/ 拆轨（图重建）都会立即把前瞻预留收回到车头物理占用格，释放被锁的区间与交叉口；解编按 id 清掉全部占用与预留，不留幽灵条目。
- **堵站排队**：站内列车装卸时占着站格，后续列车在区间外进入「等站」状态排队，前车离站后依次进站。
- **断路处理**：目标站不可达时列车进入「断路」状态原地等待，补齐轨道后下一 tick **自动重新寻路**；计划中的车站被拆除则自动跳过该站。
- **到站物料接入产线**：火车站货位与箱子同构（4 槽 ×1000），传送带可直接卸入、机械臂可在车站与熔炉/组装机/实验室间转运，并完整接入**按需物流调度**（缺口 × 在途预留 × 优先级），车站物料即产线供料。
- **列车状态机**：行驶 / 装卸 / 等站排队 / 会车等待（信号机外）/ 堵死对顶（需加侧线）/ 断路 / 停运 / 待命，车顶徽标显示载货量、车体按状态着色、已预留区间铺淡色光带，点击列车即可查看与编辑。
- **存档**：列车位置与朝向、车载货物、运输计划（站点/动作/数量/循环/停站序号/停靠计时/冷却）、调度轮转游标全部序列化；**前瞻预留不入库**（每 tick 由路径重建），占用表读档后由列车位置重建——**跨格中途的半格状态不恢复**（列车吸附回已落定格、清零跨格计时并重新寻路预留，杜绝读档瞬间无占用权"走完"跨格导致的重叠），异常存档的同格多车会被自动疏散到相邻空轨；兼容无铁路字段、无预留概念的旧存档。
- 列车占用的轨道/车站格禁止拆除（避免脱轨）；行驶中解编也能正确释放占用权（含跨格中途已移交的下一格，不留幽灵占用），车载货物落到占用格地面堆，不丢失。

### 🤝 供货合同
研究科技树中的「**供货合同**」（铁路货运之后）后解锁**交付站**（与火车站同构的轨节点，青色站台标识）：

- **接单**：选中交付站查看刷新的合同邀约（货物 / 数量 / 期限 / 科研物资奖励，按物品加工深度分三档），承接后开始计时；每站同一时间只执行一单，可手动刷新邀约。
- **分批铁路供货**：用普通运输计划把工厂产品经列车运抵交付站（可分多趟、多列车）；列车每趟只卸列车载货量以内的批次，逐次累加交付进度，交齐即完成。
- **统一争料 × 独立记账**：合同货物在运抵之前仍是全图自由货物——与**生产、施工统一争料**（施工预留和按需物流调度都可能取走，需要玩家自行安排运力/优先级）；列车卸货时合同货物按缺口**即时锁付**：从列车货位直接扣付、记入合同独立台账（实物不进站货位，**站库满也能锁付**；只计列车实际运来的货物，站内普通库存不算铁路交付），任何预算池（施工建材池、按需调度、机械臂）都盘点不到，生产/施工不可再动用。
- **科研物资奖励**：合同交齐后锁付货物被客户提走，奖励的科学包（按合同档位发放自动化/物流/化学科学包）放入交付站货位（放不下落到站格地面堆），直接接入实验室供料。
- **逾期 / 取消**：超过期限（仿真秒）合同自动终止；也可手动取消。两种情况都把全部**未交付预留（锁付货物）释放**回交付站货位（放不下落地），恢复为自由货物，无奖励。逾期后再有列车卸来的货物不再锁付。
- **超额/错卸**：列车多卸的超出缺口部分、非合同货物照常进入交付站货位，可被机械臂拉回产线继续利用。
- **拆除保护**：拆除交付站自动终止其合同，锁付货物落到站格地面堆不丢失（列车占用时与普通车站一样禁止拆除）。
- **读档幂等**：锁付/发奖只发生在列车卸货事件中，完成即出列——读档不会重放卸货，**避免重复扣货或重复领奖**；合同台账（已交付量/期限/奖励/邀约）全部随存档保存，无 contracts 字段的旧存档回退空合同，行为不变。


### 🔧 设备维护（磨损 × 维修工单 × 备件预留）
研究科技树中的「**预测性维护**」（高级电子学之后）后开启，同时解锁**备件**配方（组装机：齿轮×1 + 铁板×1）：

- **运转积累磨损**：矿机/水泵/抽油机/熔炉/组装机/化工厂/炼油厂/实验室每完成一个生产（抽水/采矿/科研）周期积累 1 点磨损；各设备有 100–160 周期的随机寿命，磨损满即**故障停机**并自动生成维修工单（图上红色闪烁 + 🛠 徽标，`S` 状态高亮同步）。磨损 ≥70% 时建筑角标变黄、右侧「维修」页给出高磨损预警。
- **按优先级预留备件**：工单分高/中/低三档，每 tick 把全图自由备件（箱子→地面物料堆）盘点为统一预算池：高优先级一层未取料前低层不分配，同级轮转公平；预留即**实体移出物流**——施工建材池、按需调度、机械臂都盘点不到，无超卖/泄漏。石炉/组装机等基础设备需备件×1，钢炉/二级组装机/化工厂/炼油厂/抽油机需备件×2。
- **停机检修 → 恢复生产**：备件齐备后停机检修 2 仿真秒（倒计时在工单上显示），检修期间设备不生产、不接料；完成后消耗备件、**磨损清零**并抽取新的随机寿命，立即恢复生产。缺件期间设备持续停机等待，补料后自动续修。
- **取消 / 拆除返还未用物料**：取消工单立即把全部预留备件返还物流（优先箱子，放不下落到设备格地面堆），设备保持故障，可在信息面板「重新报修」；拆除故障设备时其工单出列、预留备件随拆除物料一并落到地面堆，不丢失。
- **升级衔接设备与工单状态**：故障/磨损中的设备提交原地升级时，工单自动挂起并**释放预留不占料**；升级落成后磨损与故障状态迁移到新型号（高级型号不翻新设备），工单无缝接续、备件需求按新型号重算（多退少补），继续备料检修。未故障设备的磨损值同样随升级迁移。
- **存档续修**：每台设备的磨损值/寿命/故障标记与全部工单（优先级、条目级备件预留、检修计时）、归档记录均序列化；读档后继续备料检修（检修中读档不凭空完成，重新走检修倒计时），无 maintenance 字段的旧存档按科技研究状态回退（已研究则从 0 磨损开始积累、不误判故障）；工单设备已不存在时预留备件落到该格地面堆。

### ⚡ 一键流水线

不想一格一格手摆？顶栏「⚡ 流水线」或按 `P` 打开预设产线库，在地图上直接落地**一套完整工程**：

- **预设产线**（采集→运输→制造→入库，配方/机械臂/筛选全部配好）：
  - 铁矿/铜矿冶炼线：矿机 → 传送带转弯 → 机械臂装入石炉 → 成品金属板自动入箱
  - 石料采集线：矿机 → 传送带 → 箱子
  - 齿轮 / 电路板生产线：原料箱 → 组装机（多级串接）→ 成品箱
  - 自动化科学包线：三料箱环绕组装机产出科学包
  - 实验室研究组：科学包料箱经传送带总线同时投喂 3 台实验室
  - 供水站：水泵临水域 + 管道
- **智能选位**：选择后以鼠标为中心自动搜索落点——矿机自动对准对应矿脉、水泵自动紧邻水域、其余格子避开建筑/水面；找不到时预览跟随鼠标逐格标红，按 `F` 重新搜索。
- **一键施工**：预览中 `R` 旋转、左键提交整套施工计划（可连续盖章），自动从箱子/地面物料堆预留建材，缺料挂起等待，建成即接入按需物流调度立即投产。
- **科技门控**：未解锁的建筑/配方对应产线在选择器中置灰，并提示所需科技。

### 蓝图施工
- **框选生成蓝图**：按 `B`（或顶栏「📐 蓝图」）进入框选模式，左键拖拽框选已有产线，建筑布局、朝向、配方、机械臂筛选/按需、供料优先级全部存入蓝图剪贴板。
- **旋转预览**：生成后自动进入放置预览，`R` 顺时针旋转 90°（条目坐标与朝向同步旋转），逐格绿/红显示校验结果，左键提交施工计划（可连续盖章多次）。
- **科技与地形校验**：未解锁建筑、被占用格、水域/矿脉/油田等地形不符、与已有施工计划冲突的位置都会标红并阻止提交。
- **🧱 分阶段施工（按生产阶段设置前置条件）**：每个施工/升级计划可在任意两个条目之间切分为多个**顺序阶段**，为非末尾阶段设置**放行闸门**——
  - **建成放行（默认）**：阶段全部建成（含跳过）即放行后续阶段；
  - **试产达标放行**：阶段建成后还须其内生产建筑（熔炉/组装机/化工厂/炼油厂/矿机）累计完成指定次数的生产（可限定具体产物，如「炼出 3 块铁板」），下游阶段才开工；
  - 只有**活跃阶段**可以备料施工，闸门未开放的后续阶段**不占料**（每 tick 释放其预留）；活跃阶段缺料时同样联动挂起后续阶段；
  - **前置取消**：删除阶段边界（合并阶段）或把闸门改回「无」即取消前置条件，后续立即放行；把已开放闸门收紧为试产则重新挂起；
  - **建筑被拆联动**：已放行闸门的建成建筑若被拆除/替换为其他型号，该条目自动回退待建、闸门重新关闭、后续阶段立即挂起并**释放全部预留建材**；补料重建并再次达标后闸门自动重新放行；
  - **按产物归属的试产统计**：每栋生产建筑对每种产物分别累计完成次数（切换配方后旧产物的生产次数**不会**串计到新产物），试产闸门限定产物时只统计该产物自身的产量——杜绝「切配方→旧产物次数凑数→误放行后续施工」；
  - 阶段切分、闸门模式/产物/次数、试产基线（baseline，按产物分项快照）与开放状态全部**随存档保存**；无阶段字段的旧存档自动回退为单阶段无闸门，行为不变；**< 1.8.0 旧档**的试产统计读入时自动迁移（历史无归属产量不计入、可能已误开放的闸门重新核验，补产达标后自动再放行）。
- **计划优先级 × 统一建材分配**：右侧「施工」页可给每个计划设**高/中/低优先级**与**前置依赖**。每 tick 全图建材（箱子/地面物料堆）盘点为统一预算池：高优先级一层未取料前低层不分配，同级按轮转公平起步；前置计划未完工前后继计划挂起且不占料（依赖自动环检测，前置取消视为满足）。
- **缺料推进可施工部分**：前沿建筑缺料时计划挂起等待，但会跳过它先把后面**当前能一次凑齐整套建材**的建筑建成（仅限当前活跃阶段内）；物流补齐后前沿自动续建。
- **暂停 / 取消释放预留**：每种建筑有建材成本（如传送带=铁板×1、实验室=铁板×4+电路板×1），预留即移出物流（不会被机械臂取走）并按条目记账；**暂停计划立即把全部预留返还物流**，继续后重新备料；取消计划同样返还（放不下的落到地面堆），已建成部分保留。
- **接入生产调度**：落成建筑即注册进仿真核心，配方/筛选/优先级同步还原，立即纳入按需物流调度。
- **施工进度随存档恢复**：计划优先级、前置依赖、暂停态、条目级预留与蓝图剪贴板全部序列化，读档后续建；兼容旧存档（旧版计划级预留自动迁移到前沿条目，无施工字段的存档回退空计划）。

### 蓝图原地升级
- **框选批量替换**：按 `U`（或顶栏「⬆ 升级」）框选已有产线，系统自动为每栋建筑匹配**已解锁的最高级型号**——石炉→钢炉、组装机→二级组装机、传送带→快速/极速传送带、机械臂→快速机械臂；未解锁或无升级链的建筑自动跳过，预览逐栋显示目标型号与总备料成本，左键确认提交。
- **按施工计划备料、分步切换**：升级计划与蓝图施工共用统一建材池与优先级/前置依赖调度，并同样支持**分阶段闸门**（先升级一批、试产达标后再升级下一批）；按新建筑造价逐栋备料、按施工间隔逐栋原地替换，旧产线在切换前持续运转。
- **保留配方、库存与在途物料**：替换瞬间迁移配方与生产进度、输入/输出槽与流体缓存、传送带在途物品（含在途预留标签）、机械臂手持/筛选/按需与供料优先级——在途预留以消费者坐标为键，升级后自动继续履约，产线不断流。
- **暂停 / 取消返还未用建材**：暂停立即把全部已预留建材返还物流，继续后重新备料；取消同样返还（放不下的落到地面堆），已完成的升级保留。
- **兼容旧存档续建**：升级计划（目标型号/原型号/条目预留）随存档序列化，读档后续建；旧存档无升级字段的计划按普通建造处理，行为不变。

### 存档 / 读档
- 3 个手动槽位 + 自动存档（每 60 秒）。
- 完整序列化：地图、矿量、建筑（含**磨损值/寿命/故障标记**）、传送带物品（含转弯进料侧与**在途预留标签**）、机械臂筛选/手持状态、合流调度游标、**生产线供料优先级**、地面物料堆、管道流体、研究进度、统计数据、**施工/升级计划（分阶段切分/闸门模式/试产基线/优先级/前置依赖/暂停态/条目级预留）与蓝图剪贴板**、**铁路（列车位置/在途货物/运输计划/停站计时/调度游标；前瞻预留每 tick 重建不入库）**、**供货合同（锁付台账/期限/奖励/邀约）**、**维修工单（备件预留/检修计时/优先级/归档记录）**。
- 支持导出/导入 JSON 存档，方便备份与分享。

## 技术架构

UI 层使用 **React 18 + Vite** 声明式组件，仿真引擎保持零依赖的原生 JavaScript。
引擎通过事件总线（`FG.Events`）单向通知 UI，React 组件订阅事件后直接读取 `FG.game` 重渲染；
Canvas 地图/科技树渲染器封装为 React 组件，绘制逻辑不变。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

### React 与引擎的边界

- **引擎不动**：`js/` 下全部逻辑（固定步长 tick、物料/铁路/合同/维修/蓝图/存档）原样保留，
  命名空间仍是全局单例 `window.FG`，641 个无头测试零修改通过。
- **单向事件流**：引擎只 `FG.Events.emit(...)`，不引用任何 React/UI 模块；
  `src/hooks.js` 把事件桥接成组件重渲染（高频 `sim:tick` 做了 150~500ms 节流）。
- **命令式操作转发**：按钮/键盘回调直接调用 `game.*` 方法（如 `setRecipe`、`togglePause`），
  状态变化仍由事件回流到界面，没有引入第二份状态。
- **Canvas 不归 React 管像素**：`MapCanvas` / `TechTree` 只负责挂载 canvas、绑定输入与定时重绘，
  具体绘制沿用原 Renderer。

### 仿真核心
- 固定步长仿真：每秒 20 tick，支持 0.5×~4× 速度倍率。
- 传送带物品流：每格容量 4，物品沿**直行/转弯折线路径**平滑移动、尾部对齐进料。
- **转弯与多路汇入**：任意传送带都可从背部/左侧/右侧三个方向汇入（正面顶头不行），目标带按轮转（round-robin）在各上游间公平调度，合流不会饿死某一侧。
- **统一拥堵处理**：每个 tick 重置「入口占用表」，合流与机械臂共用同一入口容量检查，在途物品（带面、机械臂手上）天然占位，杜绝抢料与重复放入。
- 机械臂：从身后格抓取、向前方格放置，支持 1/2 格范围；可设置**物品筛选条件**与**按需供给**。
- **按需物流调度（需求数量 × 在途预留 × 生产线优先级）**：选中熔炉/组装机/化工厂/炼油厂/实验室可设置**供料优先级（高/中/低）**。每个 tick 调度器统一盘点消费者缺口（目标缓冲 − 库存 − 在途预留）与各料源自由货物，按「高优先级整层优先、同级轮转公平」拨付；机械臂取货时货物获得**在途预留标签**（带面上以青色环标记），沿带/机械臂转运、过环路都不会被别的产线抢走或重复投放。
  - *环路*：需求追踪沿传送带 BFS（seen 去环 + 节点数封顶），货物在环上绕行到取料臂即被取走，无死循环、无过量灌入。
  - *多消费者争料*：共享料源时高优先级产线未补足，自由料不流向低优先级产线；同级消费者轮转均分。
  - *配方切换*：切配方后旧配方的在途预留下一 tick 自动失效释放，改供新配方或其他消费者；残留物料仍可被运走。
  - *拆建*：拆除消费者/传送带/机械臂时相关预留立即释放，落地物料恢复为自由货物。
  - *读档*：调度计划每 tick 重建、无持久运行状态；在途预留标签与供料优先级随存档保存，读档后无缝继续，并兼容无这些字段的旧存档（回退普通优先级/自由货物）。
  - 每个 tick 机械臂「先统一投放、再统一取料」，取料按目标产线优先级排序，保证缺口在同一 tick 重开时高优先产线先得料。
- **物料保留**：切换配方不再清空旧槽位（残留物料标记显示，可被机械臂运走，且不阻塞新配方）；拆除建筑时传送带在途物品、机械臂手持物、槽位与箱子物料全部落到该格**地面物料堆**，原地重建建筑自动回收。
- **存档恢复调度状态**：地面物料堆、传送带物品位置与进料侧、合流轮转游标、机械臂筛选/按需开关/手持物/计时、管道液位与流体类型全部序列化，读档后流水线无缝继续。
- 管道流体：液位均衡扩散，生产建筑带缓冲罐推/拉。
- 配方驱动生产：输入/输出槽位 + 速度倍率 + 缺料/堵塞状态机。
- 铁路货运：轨格图加权 Dijkstra 寻路（拥堵/会车绕行）+ 闭塞分区前瞻预留（道岔交叉口独立、单线区间会车门）+ 轮转公平申请；列车状态机处理行驶/停站装卸/等站/会车等待/对顶堵死/断路，停运·解编·改计划·拆轨统一释放预留，车站货位复用箱子/按需调度接口接入产线供料。
- 供货合同：交付站邀约/接单，列车卸货事件驱动锁付（独立台账、移出物流），分批交齐发科研包，逾期/取消释放锁付，存档幂等。
- 设备维护：生产设备随运转积累磨损，磨损满故障停机并自动开单；工单按优先级从统一备件池预留（移出物流），齐备后停机检修、磨损清零恢复；取消/拆除返还未用备件，升级衔接设备与工单状态，全部随存档保存续修。
